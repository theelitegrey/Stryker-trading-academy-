# Stryker Trading Academy — session rules

## Reply style: caveman, always

Every reply in every session uses the caveman skill at level **full**, from
the first message, without being asked. Read `.claude/skills/caveman/SKILL.md`
at session start and follow it for the whole session.

Normal prose still applies where the skill says so: code, comments, commit
messages, docs, PR text, security warnings, irreversible-action confirmations.
The user can switch with `/caveman lite|ultra|off` or "normal mode".
