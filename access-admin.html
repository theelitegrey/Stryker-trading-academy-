Roles & access

Control which role (plan tier) is required to unlock each page, chapter, and trading model.

Roles here are your existing Plans (Starter, Pro, Elite, or whatever you've named them) — set each plan's rank and tag color on the Plans page first. A page or item with no restriction set below is open to any signed-in student. Individual chapters/models can be restricted from their own editor — but for the common case of "this role can only see up to chapter N," set each plan's Chapter access field on the Plans page instead (e.g. "5" for Starter → chapters 1-5, "all" for Elite) — no per-chapter setup needed. Each page below also has an optional view-only tier — a role at or above it can see the page but not interact (currently wired up for the Trading Floor: view-only students can browse posts and replies but can't post, react, or reply).
