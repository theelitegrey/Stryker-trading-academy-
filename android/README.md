# TradeZoro Android app (Trusted Web Activity)

Wraps https://tradezoro.com. The app is a thin shell; the site is the app. No separate code.

- Project: android/app-project (generated by Bubblewrap CLI 1.27; settings in twa-manifest.json)
- Package com.tradezoro.app, minSdk 24, targetSdk 36, versionCode 1
- Play listing material: android/store/
- Upload keystore: NOT in the repo. /root/.hermes/profiles/chief-of-staff/secrets/android/tradezoro-upload.jks (password file next to it)
- Digital Asset Links: /.well-known/assetlinks.json (repo root). After Play App Signing is on, add the Play signing-key SHA-256 as a second fingerprint.
- The deploy workflow leaves android/ out of the site.

Build (needs JDK 17, Android SDK in /root/android-sdk with platforms;android-36 and build-tools 36):
  cd android/app-project
  export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ANDROID_HOME=/root/android-sdk
  ./gradlew assembleRelease bundleRelease
  zipalign + apksigner sign the apk, jarsigner the aab with the upload key.
Raise appVersionCode in twa-manifest.json and app/build.gradle for every Play upload.
