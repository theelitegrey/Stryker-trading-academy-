# Data safety form draft (from the site's real behaviour and https://tradezoro.com/privacy)

Draft only. The Owner or Website Manager must confirm against the privacy policy before submitting.

General
- Does the app collect or share user data: Yes.
- Is all data encrypted in transit: Yes (HTTPS only, HSTS on).
- Can users ask for data deletion: Yes, by email to support@tradezoro.com and account settings (confirm with Support that deletion is offered; Play also requires a web link for account deletion: use https://tradezoro.com/privacy or a dedicated page if one is built).
- Third-party advertising or ad SDKs: none. The site says "no ads, no tracking".
- Analytics: no third-party analytics found in the site code. The cookie notice stores analytics=false. If analytics is added later, update this form.

Data collected (all needed for app functions, linked to the user, not used for advertising)
- Personal info: email address, name or display name, profile photo (when signing in with Google). Purpose: account management, app functionality.
- User IDs: account ID. Purpose: account management.
- Financial info: purchase history (plan, amount, payment reference). Card and UPI details are handled by the payment processors and never seen or stored by TradeZoro. Purpose: app functionality (access to paid plans).
- App activity: course progress, achievements, journal entries, chart layouts, alerts, community posts. Purpose: app functionality.
- Photos and files: none unless the user uploads an avatar or chart image (optional).
- Device or other IDs: push notification token (when the user turns notifications on). Purpose: app functionality (alerts).
- Location: not collected. Precise or approximate location: no. (Country is inferred from the network address only to apply the regional block; not stored as location data. Confirm with the engineer.)
- Contacts, calendar, SMS, microphone, camera, health: not collected. The site blocks camera, microphone and geolocation by policy.

Data shared with third parties
- Payment processors receive what is needed to take a payment. Play treats a payment processor as a service provider, so this is usually not counted as "sharing". Confirm.
- Cloud hosting and authentication providers process data for TradeZoro as service providers.
- Data sold: No.

Security practices
- Encrypted in transit: Yes.
- Deletion request route: Yes (see above).
- Independent security review: No.
