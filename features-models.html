What lives inside every model

Each model in the library is written to the same standard — if a step is not defined, the model is not published.

Market context

What has to be true before the setup is even valid — draw on liquidity, session, higher-timeframe narrative.

Entry trigger

The exact confirmation that puts you in — defined precisely enough that two students take the same trade.

Invalidation

Where the idea is wrong, decided before entry — the stop is part of the model, not an afterthought.

Partials, break-even rules, and targets — what you do after the fill, written down.
