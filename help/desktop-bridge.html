Desktop Bridge: step by step

Beta · Windows · Version 1.0.0 · Last updated 4 November 2026

The TradeZoro Data Bridge is a small program for Windows. It reads prices from your own MetaTrader 5, NinjaTrader 8 or Interactive Brokers (TWS or IB Gateway), and hands them to a chart in your browser. Pick a platform below, or read the safety notes first.

What it does, in plain words
  • Prices stay on your own computer and browser. They go from your platform to the helper to your browser tab. They never go through TradeZoro servers.
  • For your own use only. It shows your own data feed to you. Do not share or redistribute it. Your platform and data provider terms still apply.
  • It never places orders. It cannot buy, sell, change or cancel anything, and it does not read your balance or positions.
  • Use Chrome, Edge or Firefox. Safari does not allow this connection. Brave works after you allow it in Shields.

Education only. Not financial advice.

1. Before you download: Windows will warn you

The helper is not code-signed yet. Windows will show a warning because it does not know the publisher, not because anything was found. Click More info, then Run anyway. Your antivirus may also ask. We publish a checksum so you can check the file yourself (section 6).

2. Download

  1. On a ZoroCharts page open Data source, pick your platform, then Pair. Read the heads-up and use the download link. Or use these links:
  • TradeZoroBridge.exe (MetaTrader 5 and Interactive Brokers)
  • TradeZoroBridge-NT8.zip (NinjaTrader 8 add-on)
  • All files and checksums

Your browser may also say the file is "not commonly downloaded". Choose Keep.

3. The Windows SmartScreen warning

Double-click TradeZoroBridge.exe. If you see the blue box:

  1. Click More info.
  2. Click Run anyway.

Antivirus notes

  • Small unsigned programs are sometimes flagged by mistake. If your antivirus blocks or quarantines the file, check the checksum first (section 6). If it matches, restore the file and add it to the allowed list.
  • Windows Defender may scan it for a few seconds the first time. Wait for it to finish.
  • If you do not feel comfortable, do not run it. The chart sources that need no download (Alpaca, tastytrade and others) still work.
  • Windows Firewall may ask about network access. The helper only listens on 127.0.0.1, which is your own computer. You can choose Cancel or allow private networks. It does not need public access.

4. The pairing code

When the helper starts it opens a window with an 8-digit code (valid for 2 minutes). Type it into TradeZoro. After the first time you do not need a code again.

5a. MetaTrader 5

  1. Open MetaTrader 5 and log in. The investor (read-only) password is enough and is the safer choice.
  2. Start TradeZoroBridge.exe from a Command Prompt: TradeZoroBridge.exe mt5, or double-click it and choose MetaTrader 5 if asked.
  3. Note the pairing code in the window.
  4. In TradeZoro: Data source, then MetaTrader 5, then Pair. Type the code.
  5. Open a chart and type the symbol like byo:EURUSD. Use the symbol name as it appears in your Market Watch.

5b. Interactive Brokers (TWS or IB Gateway)

  1. Open TWS or IB Gateway and log in.
  2. Go to File > Global Configuration > API > Settings (in IB Gateway: Configure > Settings > API > Settings).
  3. Tick Enable ActiveX and Socket Clients, tick Read-Only API, and tick Allow connections from localhost only. The socket port is 7497 (paper) or 7496 (live).
  1. Start the helper: TradeZoroBridge.exe ibkr --tws-port 7496 (or 7497 for paper).
  2. In TradeZoro: Data source, then Interactive Brokers, then Pair. Type the code.
  3. Open a chart with byo:AAPL or a futures name such as byo:ES 12-26.

Good to know: TWS itself sends your account numbers to any program that connects to it. The helper ignores them and never logs or sends them. Live prices need your own Interactive Brokers market data subscriptions, which may have fees.

5c. NinjaTrader 8

  1. Download TradeZoroBridge-NT8.zip. Do not unzip it.
  2. In the NinjaTrader Control Center choose Tools > Import > NinjaScript Add-On and pick the zip. NinjaTrader compiles it on import. If a compile error shows, see "When it does not connect".
  1. Open New > NinjaScript Output. It prints the port (48715 to 48719) and the 8-digit code. The add-on starts with NinjaTrader after that.
  2. In TradeZoro: Data source, then NinjaTrader, then Pair. Type the code.
  3. Open a chart with the NinjaTrader instrument name, for example byo:ES 12-26.

Beta note: the NinjaTrader add-on has not yet been tested on a live NinjaTrader 8, and has no market depth. If it will not import, see "When it does not connect" below, then tell support which NinjaTrader version you have.

Connect in TradeZoro

  1. Open a chart (ZoroCharts) in Chrome, Edge or Firefox.
  2. Open Data source, choose your platform, press Pair.
  3. Your browser may ask to allow tradezoro.com to connect to apps on this device. Choose Allow. This is the helper on your own computer.
  4. Type the 8-digit code. The status changes to Connected.

6. Check the file (SHA-256)

This proves the file is the one we published. In Command Prompt, go to your Downloads folder and run:

certutil -hashfile TradeZoroBridge.exe SHA256

The long string it prints must match this one exactly (version 1.0.0):

TradeZoroBridge.exe
71a25f8269f854952c6b2445db630f7fd71ac6a2d1db9281deb0c1fc2aa12e33

TradeZoroBridge-NT8.zip
07d4551a5b1f5f321b2f5a478e178176f16b86dc2393cecf5e3c3d1221d8efba

Use certutil -hashfile TradeZoroBridge-NT8.zip SHA256 for the NinjaTrader file. The same numbers are in the release notes and in SHA256SUMS.txt on the release page. If they do not match, do not run the file. Download again, and if it still differs, contact support.

When it does not connect

  • "Could not reach the helper". The helper window is not open. Start it, then press Pair again. Keep the window open while you chart.
  • The browser did not ask, or I clicked Block. Click the lock icon in the address bar, open site settings, set local network access (or "apps on this device") for tradezoro.com to Allow, then reload.
  • Safari. Safari does not allow this. Use Chrome, Edge or Firefox.
  • Brave. Open the Shields icon and allow local connections for tradezoro.com.
  • Code not right or expired. The code lasts 2 minutes and changes after 5 wrong tries. Close the helper and start it again for a new code.
  • "Pairing no longer valid". Choose Forget in the Data source sheet, then pair again.
  • Port in use. The helper tries ports 48715 to 48719. Close other copies of the helper.
  • Interactive Brokers: connection refused. Check Enable ActiveX and Socket Clients is on and the port matches 7496 or 7497. Make sure TWS is logged in.
  • Interactive Brokers: no live prices. You need your own market data subscription for that exchange.
  • MetaTrader 5: symbol not found. Use the exact name from Market Watch. The helper starts only after MetaTrader 5 is logged in.
  • NinjaTrader: "Import failed. The NinjaScript Archive File may contain duplicate method names..." This message means NinjaTrader could not compile the add-on on your PC. Try these in order:
    1. Remove any older copy first. In NinjaTrader open New > NinjaScript Editor, open the AddOns folder, right-click TradeZoroBridge and choose Remove. Close the editor.
    2. Download the latest TradeZoroBridge-NT8.zip from the release page above. Earlier downloads needed an extra system reference and fail on a normal NinjaTrader; the current file does not.
    3. Import the zip as it is. Do not unzip it. Use Tools > Import > NinjaScript Add-On.
    4. Check your version under Help > About. You need NinjaTrader 8.1 or newer.
    5. If another script on your PC already has errors, NinjaTrader refuses every import. Open the NinjaScript Editor and press F5: if it lists errors in other files, fix or remove those files first.
    Still failing? Send support your NinjaTrader version and a screenshot of the error.
  • Windows blocked the file. Right-click the file, choose Properties, tick Unblock if shown, then run again.
  • Work or school computer. Company rules may block unsigned programs. Ask your IT team or use another source.

Still stuck? Get help on Discord (#help-and-support channel).

7. Quit or uninstall

  • Quit: close the helper window (or press Ctrl+C in it). The chart goes quiet straight away. For NinjaTrader, close NinjaTrader or remove the add-on.
  • Disconnect in TradeZoro: Data source, your platform, Forget this connection.
  • Remove the pairing on your PC: TradeZoroBridge.exe mt5 --revoke (or ibkr).
  • Uninstall: there is no installer. Delete TradeZoroBridge.exe, and delete the folder %APPDATA%\TradeZoroBridge to remove the saved pairing. For NinjaTrader delete TradeZoroBridge.cs from Documents\NinjaTrader 8\bin\Custom\AddOns and recompile.

The helper only listens on 127.0.0.1 and only accepts connections from tradezoro.com. Prices are never sent to TradeZoro. Education only. Not financial advice.
