Unicorn Model

CCommunity CommunityFree Updated Nov 4, 2026
Add to chart

Unicorn and breaker model setups after sweeps, with HTF candles, multi-timeframe liquidity, session levels, FVGs, and SMT.

Community script. The script does not name its author. No licence is stated in the script. TradeZoro did not write it. ZoroCharts runs it as the author published it, and its source code is not shown here.

Overview

This community script looks for the ICT Unicorn model: a breaker block that overlaps a fair value gap after liquidity is taken. It can show only Unicorn setups or breakers too, with potential setups drawn before confirmation and invalidated ones in a ghost color.

How it works

Liquidity sources use OHLC levels plus swing points from each source timeframe, mapped automatically or set by you. A setup forms when price sweeps a level, breaks structure, and leaves a breaker overlapping an FVG.

The stop sits at the manipulation extreme, and targets are drawn at the R multiples you list. Optional parts include a break-even move at 50%, a daily cap on how many setups can reach target or stop, a breaker size filter and a time filter. SMT uses a pair mapped automatically or set manually.

How to use it

  • Use it to see where a breaker and an FVG overlap after a sweep.
  • Some traders keep the higher-timeframe candles on screen to stay aware of the bigger candle.
  • Use the liquidity lines to see which levels have been swept.

These are ways some traders read it, for learning. They are not trade signals.

Alerts

Notes and limits

  • Up to 50 setups are kept in history by default.
  • Targets, stops and limits follow the script's own rules.
  • SMT and multi-timeframe liquidity need extra data requests.
