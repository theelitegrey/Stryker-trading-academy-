Publishing is free for everyone. You can share a script openly, or sell it through Creator Hub.

## Publish a script

1. Open your script in the editor and press **Publish**.
2. Give it a name and a short description. Pick a category.
3. Choose how people get it:
   - **Open source**: anyone who adds it can read the code.
   - **Protected**: people can use it but not read it.
4. Choose **free** or **paid**.
5. Add a short note about what changed in this version.

The script then appears in the Script Library. Each time you publish again, you add a new version. People who already use your script can update when they choose.

## Protected scripts

When you publish a protected script, the source never leaves your account. We compile it, seal the compiled program on our server, and only send it to people who are allowed to use it. Paid and protected scripts run only for people who have it. Nobody else is sent the code.

A protected script runs in the same sandbox as every other script. It cannot reach the network, your storage or the page.

## Selling

A paid script is listed in Creator Hub like other creator products. Payouts work the same way as the rest of Creator Hub; see the Creator Hub rules for the payout terms. We do not publish prices in this manual: you set yours in the publish dialog.

## Rules for listings

- Describe honestly what the script does.
- Do not claim profit, win rates or results. Education only. Not financial advice.
- Sample screenshots must say "Sample".
- A script that tries to break the sandbox, hide what it does, or harm the viewer is removed.

## Data in published scripts

If your script uses book, flow, GEX or options data, people who run it see that data only if their plan includes it, exactly as on a chart. Say so in your description so nobody is surprised.
