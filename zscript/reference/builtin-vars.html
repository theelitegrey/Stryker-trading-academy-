Built-in variables

Values that exist in every script, such as close, bar_index and barstate.islast.

bar_index

Bar number, 0 for the first bar.

Returns: a whole number

barstate.isconfirmed

True when the bar is closed.

Returns: true or false

barstate.isfirst

True on the first bar.

Returns: true or false

barstate.ishistory

True on history bars.

Returns: true or false

barstate.islast

True on the last bar.

Returns: true or false

barstate.islastconfirmedhistory

True on the last closed history bar.

Returns: true or false

barstate.isnew

True on the first update of a bar.

Returns: true or false

barstate.isrealtime

True on live bars.

Returns: true or false

close

Close price of the bar (the latest price on the live bar).

Returns: a number

dayofmonth

Day of the month (UTC).

Returns: a whole number

dayofweek

Day of the week, 1 = Sunday ... 7 = Saturday (UTC).

Returns: a whole number

high

High price of the bar.

Returns: a number

hl2

(high + low) / 2.

Returns: a number

hlc3

(high + low + close) / 3.

Returns: a number

hlcc4

(high + low + close + close) / 4.

Returns: a number

hour

Hour (UTC).

Returns: a whole number

last_bar_index

Bar number of the last loaded bar.

Returns: a whole number

low

Low price of the bar.

Returns: a number

minute

Minute.

Returns: a whole number

month

Month of the bar, 1-12 (UTC).

Returns: a whole number

ohlc4

(open + high + low + close) / 4.

Returns: a number

open

Open price of the bar.

Returns: a number

second

Second.

Returns: a whole number

syminfo.currency

Quote currency.

Returns: text

syminfo.mintick

Tick size.

Returns: a number

syminfo.pointvalue

Value of one point move for one contract.

Returns: a number

syminfo.ticker

Symbol without exchange, e.g. "NQ".

Returns: text

syminfo.tickerid

Full symbol id.

Returns: text

syminfo.type

Market type: "futures", "crypto", "stock", "forex", "index".

Returns: text

time

Bar open time, ms since 1970 (UTC).

Returns: a whole number

time_close

Bar close time, ms since 1970 (UTC).

Returns: a whole number

timeframe.isdaily

True on daily charts.

Returns: true or false

timeframe.isintraday

True for minute and second timeframes.

Returns: true or false

timeframe.isminutes

True for minute timeframes.

Returns: true or false

timeframe.ismonthly

True on monthly charts.

Returns: true or false

timeframe.isseconds

True for second timeframes.

Returns: true or false

timeframe.isweekly

True on weekly charts.

Returns: true or false

timeframe.multiplier

Number part of the timeframe.

Returns: a whole number

timeframe.period

Chart timeframe, e.g. "5", "60", "D".

Returns: text

volume

Volume of the bar.

Returns: a number

weekofyear

Week number of the year (ISO).

Returns: a whole number

year

Year of the bar (UTC).

Returns: a whole number
