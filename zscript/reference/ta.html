Indicators (ta)

Moving averages, oscillators, volatility and pattern helpers. Each call keeps its own running memory, so call them on every bar.

ta.accdist

Accumulation/distribution.

Returns: a number

ta.alma(source, length, offset=0.85, sigma=6)

Arnaud Legoux moving average. Call on every bar: it keeps its own running memory.

Returns: a number

ParameterTypeNotes
sourcenum
lengthint
offsetfloatDefault 0.85
sigmafloatDefault 6

ta.atr(length)

Average true range (RMA of the true range). Call on every bar: it keeps its own running memory.

Returns: a number

ParameterType
lengthint

Returns: a whole number

ParameterType
